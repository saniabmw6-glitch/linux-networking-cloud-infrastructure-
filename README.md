Linux, Networking & Cloud Infrastructure

Project Overview

A hands-on cloud infrastructure project using AWS EC2 and Ubuntu Linux.

Technologies Used

- AWS EC2
- Ubuntu Server 24.04
- Linux CLI
- SSH
- Networking
- AWS Security Groups
- Nginx
- HTML

Project Objectives

- Launch an Ubuntu EC2 instance.
- Connect using SSH.
- Practice Linux commands.
- Manage users, groups and permissions.
- Understand IP addressing, DNS and ports.
- Configure AWS Security Groups.
- Deploy a website using Nginx.

Project Structure

- screenshots/ — Project screenshots
- website/ — HTML website
- linux-commands.md — Linux commands
- networking.md — Networking documentation

Learning Outcomes

Practical experience with Linux administration, AWS cloud infrastructure, networking and web server deployment.
